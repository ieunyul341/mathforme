# 고1 공통수학2 · 통합과학2 30일 학습 대시보드 V2.4

GitHub Pages에 그대로 업로드해 사용하는 정적 웹앱입니다. 기존 30일 학습 계획, 전체 캘린더, 1·3·7·14·30일 간격 복습, 한 장 결과물, 50분 집중·10분 휴식 타이머를 유지하면서 **학습 ✓/✕ 상태, 미완료 자동 이월, 복습한 실제 범위 기록**을 추가했습니다.

## V2.4에서 추가된 기능

### 1. 오늘 할 일 ✓ 완료 / ✕ 못함

Day 상세 화면의 모든 학습 항목에 두 개의 버튼이 표시됩니다.

- `✓ 완료`: 오늘 계획대로 끝낸 항목
- `✕ 못함`: 오늘 끝내지 못한 항목
- 선택한 버튼을 다시 누르면 미정 상태로 되돌아갑니다.

대상은 정승제 강의, 개념원리, 마플 시너지, 김청해 강의, 오투, 완자 기출픽, 영어 지문, 매3비, 학교 수업 복습, 한 장 결과물입니다.

### 2. ✕ 항목 자동 이월

`✕ 못함`을 누르면 해당 항목이 다음 날 할 일에 자동으로 추가됩니다.

- 대시보드의 `오늘로 넘어온 할 일`
- 다음 날 Day 상세의 `이전 날에서 넘어온 할 일`
- 전체 캘린더의 `이월` 표시
- 날짜 상세 화면의 밀린 할 일 목록

이월 항목에서도 실제로 끝낸 페이지·문제 번호를 적고 `✓ 오늘 완료`를 누를 수 있습니다. 다시 못했다면 `✕ 다시 이월`을 눌러 그다음 날로 넘깁니다. 이월 완료 후에는 원래 Day 진도에도 `이월 완료`로 반영됩니다.

### 3. 복습할 때 실제 범위 기록

복습 성공 또는 다시를 누르기 전에 다음 내용을 입력합니다.

- 이번에 실제로 복습한 강의 구간
- 교재 페이지와 문제 번호
- 막힌 부분과 다음에 확인할 내용

예시:

```text
개념원리 p.56~67 · 필수예제 8~15
마플 시너지 121~138번
정승제 10~12강 중 원과 직선의 위치 관계
```

기록은 복습 성공·실패 이력과 함께 저장되며, 최근 복습 기록을 카드에서 다시 펼쳐볼 수 있습니다.

### 4. 복습 일정 직접 추가

`복습 관리 → 복습 일정 직접 추가`에서 그날 실제로 공부한 범위를 자유롭게 등록할 수 있습니다.

- 과목
- 복습 제목·단원
- 실제 공부 범위·페이지·문제 번호
- 다음에 안 보고 답할 질문
- 학습 기준일

등록하면 설정된 복습 주기 1·3·7·14·30일에 자동 배치됩니다.

## 저장과 백업

체크 상태, ✕ 상태, 이월 일정, 복습 범위, 오답, 백지 복습, 한 장 결과물 텍스트, 공부시간은 현재 브라우저에 자동 저장됩니다.

`진도 백업`을 누르면 JSON 파일이 다운로드됩니다. JSON에는 다음 데이터가 포함됩니다.

- ✓/✕ 학습 상태와 이월 처리 이력
- 강의·교재·국어·영어 진도
- 복습한 실제 범위와 성공·다시 기록
- 직접 추가한 복습 일정
- 오답·백지 복습·학교 복습 텍스트
- 50·10 타이머의 공부시간 기록
- 시작일·개학일·복습 주기 설정

첨부 이미지와 PDF 원본은 JSON에 포함되지 않습니다. 첨부 파일은 현재 브라우저의 IndexedDB에만 저장됩니다.

## 기존 V2.3에서 업데이트

1. 현재 사이트에서 먼저 `진도 백업`을 눌러 JSON 파일을 보관합니다.
2. 이 폴더의 파일로 GitHub 저장소 파일을 교체합니다.
3. 같은 GitHub Pages 주소를 같은 Safari에서 열면 기존 데이터가 유지됩니다.
4. 데이터가 보이지 않을 때 `백업 불러오기`로 기존 JSON을 선택합니다.

V2.3 백업의 기존 체크·텍스트·복습·타이머 기록을 읽을 수 있습니다. 새 기능의 ✕·이월·복습 범위 기록은 V2.4에서 사용하기 시작한 이후부터 추가됩니다.

## GitHub Pages 업로드

1. ZIP 압축을 풉니다.
2. 폴더 **안의 파일 전체**를 GitHub 저장소 최상위에 업로드합니다.
3. `index.html`이 저장소 루트에 있는지 확인합니다.
4. `Settings → Pages`로 이동합니다.
5. Source는 `Deploy from a branch`, Branch는 `main`, Folder는 `/(root)`로 설정합니다.
6. 배포 후 기존 화면이 보이면 Safari를 새로고침하거나 홈 화면 앱을 종료한 뒤 다시 엽니다.
