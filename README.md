# 고1 공통수학2 · 통합과학2 30일 학습·복습 대시보드 V7

GitHub Pages에 그대로 올려 사용할 수 있는 서버 없는 정적 웹앱입니다. 기존 30일 학습·간격 복습·한 장 결과물 기능에 **50분 집중 + 10분 휴식 공부시간 타이머**와 과목별 실제 공부시간 기록을 추가했습니다.

## 이번 버전에 추가된 50·10 타이머

- 기본 50분 집중 / 10분 휴식
- 집중 시작·일시정지·재개·현재 단계 초기화
- 집중을 끝까지 마치면 50분 학습 세션 자동 기록
- 중간에 마쳐도 `기록하고 종료`로 실제 공부한 시간 저장
- 휴식 완료 후 다음 집중 단계 준비
- 다음 단계 자동 시작 여부 설정
- 집중·휴식 시간 직접 변경 가능
- 수학·과학·영어·국어·학교 수업·복습·기타로 과목 분류
- 오늘 할 일 이름을 함께 기록
- 오늘 총 집중시간·기록 세션·완료 사이클 표시
- 과목별 공부시간 및 오늘 계획 대비 측정시간 표시
- 최근 7일 공부시간 차트
- 오늘 세션별 시작·종료 시각과 실제 측정시간 확인
- Day 상세 화면에서 해당 강의·교재·지문을 타이머 과제로 바로 전송
- 실행 중에는 다른 화면에서도 볼 수 있는 미니 타이머 표시
- 지원되는 브라우저에서는 집중 중 화면 꺼짐 방지 시도
- 기본 알림음 사용 여부 설정

타이머는 단순히 1초씩 숫자를 줄이는 대신 **예정 종료 시각**을 저장하고 현재 시각과 다시 비교합니다. Safari가 잠시 백그라운드 상태가 되더라도 대시보드로 돌아오면 남은 시간을 실제 시각에 맞춰 다시 계산합니다. 다만 아이패드가 잠겨 있거나 Safari가 오래 백그라운드에 있으면 알림음은 정확한 순간보다 늦게 들릴 수 있습니다.

## 바로 실행

`index.html`을 브라우저로 열어도 기본 기능을 쓸 수 있습니다. 오프라인 캐시와 PWA 설치 기능까지 확인하려면 로컬 서버 또는 GitHub Pages에서 실행하세요.


## 아이패드 Safari에서 타이머 사용

1. GitHub Pages 대시보드를 Safari에서 엽니다.
2. 공유 버튼을 눌러 `홈 화면에 추가`하면 앱처럼 실행할 수 있습니다.
3. 타이머 화면에서 과목과 할 일을 선택하고 `집중 시작`을 누릅니다.
4. 집중 중 화면을 계속 켜두면 가장 안정적으로 종료음이 작동합니다.
5. 다른 앱으로 이동하거나 화면을 잠가도 실제 종료 시각 기준으로 남은 시간은 보정되지만, iPadOS 정책 때문에 백그라운드 알림음이 즉시 재생된다고 보장할 수는 없습니다.
6. 공부가 끝나면 `기록하고 종료`를 눌러 실제 집중한 시간을 남길 수 있습니다.

## 데이터 저장과 백업

진도·텍스트·복습 기록·타이머 설정·공부시간 세션은 현재 브라우저의 `localStorage`에 자동 저장됩니다. 첨부 이미지/PDF는 `IndexedDB`에 저장됩니다.

`진도 백업`으로 내려받는 JSON에는 다음 항목이 포함됩니다.

- 날짜·시간표·복습 주기 설정
- 강의와 교재 완료 상태
- 영어·매3비 기록
- 오답·백지 복습·한 장 결과물 텍스트
- 타이머 집중/휴식 설정
- 과목별 공부시간 세션과 기록

첨부 이미지/PDF 원본은 JSON에 포함되지 않습니다. 브라우저 데이터 삭제, 시크릿 모드 종료, 기기 변경 등에 대비해 일주일에 한 번과 GitHub 파일 교체 전에 백업하는 것을 권장합니다.

기존 V6/V2.2와 같은 GitHub Pages 주소와 같은 Safari를 계속 사용하면 기존 저장 데이터가 유지되도록 저장 키를 그대로 사용합니다. 그래도 업데이트 직전에는 `진도 백업`을 먼저 눌러 안전한 복사본을 만들어 두세요.

## GitHub Pages 배포·업데이트

1. ZIP 압축을 풉니다.
2. GitHub 저장소 최상위에 폴더 안의 파일을 모두 업로드합니다. `index.html`이 루트에 있어야 합니다.
3. 저장소의 `Settings → Pages`로 이동합니다.
4. `Build and deployment → Source`에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, Folder는 `/(root)`로 지정하고 저장합니다.
6. 기존 버전을 교체하는 경우 파일들을 덮어쓴 뒤 GitHub Pages 배포가 완료될 때까지 잠시 기다립니다.
7. 오래된 화면이 보이면 Safari에서 페이지를 새로고침하거나 홈 화면 앱을 한 번 종료하고 다시 엽니다.
