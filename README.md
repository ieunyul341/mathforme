# 고1 공통수학2 · 통합과학2 30일 학습 대시보드 V2.5

GitHub Pages에 그대로 업로드해 사용하는 정적 웹앱입니다. V2.4의 30일 학습 계획, 전체 캘린더, 1·3·7·14·30일 복습, 한 장 결과물, 50분 집중·10분 휴식 타이머, ✓/✕ 상태, 미완료 자동 이월 기능을 유지하면서 **△ 이월완료 표시와 영단어 2유닛 루틴**을 추가했습니다.

## V2.5에서 추가·변경된 기능

### 1. △ 이월완료 표시

오늘 못한 항목을 `✕ 못함`으로 표시하면 다음 날 할 일로 넘어갑니다. 다음 날 이월 항목을 완료하면 원래 Day에는 다음처럼 남습니다.

```text
△ 이월완료
미뤘지만 완료
```

이 항목은 대시보드의 30일 완성도와 Day 완료 계산에는 **완료로 반영**됩니다. 즉, 미뤘더라도 나중에 실제로 끝내면 그 날짜의 빠진 칸을 메워주는 구조입니다.

### 2. 이월 기록은 남기고 완성도는 완료 처리

예시:

```text
8월 7일
개념원리 ✕ 못함

8월 8일
이월된 개념원리 ✓ 오늘 완료

결과
8월 7일 개념원리: △ 이월완료
8월 7일 완성도: 완료 항목으로 계산
```

단, 원래 Day의 모든 필수 항목이 채워져야 해당 날짜가 100% 완료로 계산됩니다.

### 3. 영단어 2유닛 매일 루틴 추가

국어·영어 루틴에 다음 항목이 추가되었습니다.

- 영어 독해 지문 1개
- 영단어 2유닛
- 매3비 비문학 지문 1개

영단어는 매일 새 유닛 2개를 진행합니다.

```text
Day 1: 새 단어 Unit 1~2
Day 2: 전날 Unit 1~2 복습 + 새 단어 Unit 3~4
Day 3: 전날 Unit 3~4 복습 + 새 단어 Unit 5~6
```

영단어는 별도의 1·3·7·14·30일 복습 트랙으로 만들지 않고, **매일 할 일**로만 들어갑니다. 대신 `✕ 못함`으로 표시하면 수학·과학처럼 다음 날로 이월됩니다.

### 4. 영단어 실제 학습 기록칸

Day 상세 화면에서 영단어 항목에도 실제로 외운 범위를 적을 수 있습니다.

```text
새 Unit 3~4, 복습 Unit 1~2, 헷갈린 단어 8개
```

이 텍스트는 브라우저 자동 저장과 `진도 백업` JSON에 포함됩니다.

### 5. 시간 설정에 영단어 추가

상단의 `학습 시간 설정`에서 영단어 시간을 따로 조정할 수 있습니다. 기본값은 20분입니다.

## 저장과 백업

체크 상태, ✕ 상태, △ 이월완료 상태, 이월 일정, 영단어 유닛 기록, 복습 범위, 오답, 백지 복습, 한 장 결과물 텍스트, 공부시간은 현재 브라우저에 자동 저장됩니다.

`진도 백업`을 누르면 JSON 파일이 다운로드됩니다. JSON에는 다음 데이터가 포함됩니다.

- ✓/✕/△ 학습 상태와 이월 처리 이력
- 강의·교재·국어·영어·영단어 진도
- 영단어 실제 학습 유닛 기록
- 복습한 실제 범위와 성공·다시 기록
- 직접 추가한 복습 일정
- 오답·백지 복습·학교 복습 텍스트
- 50·10 타이머의 공부시간 기록
- 시작일·개학일·복습 주기 설정

첨부 이미지와 PDF 원본은 JSON에 포함되지 않습니다. 첨부 파일은 현재 브라우저의 IndexedDB에만 저장됩니다.

## 기존 버전에서 업데이트

1. 현재 사이트에서 먼저 `진도 백업`을 눌러 JSON 파일을 보관합니다.
2. 이 폴더의 파일로 GitHub 저장소 파일을 교체합니다.
3. 같은 GitHub Pages 주소를 같은 Safari에서 열면 기존 데이터가 유지됩니다.
4. 데이터가 보이지 않을 때 `백업 불러오기`로 기존 JSON을 선택합니다.

V2.3·V2.4 백업의 기존 체크·텍스트·복습·타이머 기록을 읽을 수 있습니다. 새 기능의 영단어 기록과 △ 이월완료 표시는 V2.5에서 사용하기 시작한 이후부터 추가됩니다.

## GitHub Pages 업로드

1. ZIP 압축을 풉니다.
2. 폴더 **안의 파일 전체**를 GitHub 저장소 최상위에 업로드합니다.
3. `index.html`이 저장소 루트에 있는지 확인합니다.
4. `Settings → Pages`로 이동합니다.
5. Source는 `Deploy from a branch`, Branch는 `main`, Folder는 `/(root)`로 설정합니다.
6. 배포 후 기존 화면이 보이면 Safari를 새로고침하거나 홈 화면 앱을 종료한 뒤 다시 엽니다.
