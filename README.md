## 바로 실행

`index.html`을 브라우저로 열어도 기본 기능을 쓸 수 있습니다. 오프라인 캐시와 PWA 설치 기능까지 확인하려면 로컬 서버 또는 GitHub Pages에서 실행하세요.

```bash
python -m http.server 8000
```

- 시작일을 정하면 30일 본학습 종료일과 최종 복습일 자동 계산

- 30일치 강의·교재·영어 지문·매3비 지문·한 장 결과물 미션
- 전체 월간 캘린더에서 강의, 국어·영어 지문, 9월 모의고사, +1/+3/+7/+14/+30일 복습 미리 보기

- 이미지/PDF 결과물 첨부(현재 브라우저 IndexedDB에만 저장)
- JSON 진도 백업·복원
- 다크 모드, 모바일·태블릿 반응형, 오프라인 캐시

## 데이터 저장 주의

진도·텍스트·복습 기록은 브라우저의 `localStorage`에 저장됩니다. 첨부 이미지/PDF는 `IndexedDB`에 저장됩니다. 브라우저 데이터 삭제, 시크릿 모드 종료, 기기 변경 시 사라질 수 있으므로 상단의 **진도 백업**을 정기적으로 사용하세요.

JSON 백업에는 첨부 파일 자체가 들어가지 않습니다. 첨부 원본은 별도로 보관하세요.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 파일들을 저장소 최상위에 업로드합니다. `index.html`이 루트에 있어야 합니다.
3. 저장소의 `Settings → Pages`로 이동합니다.
4. `Build and deployment → Source`에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, Folder는 `/(root)`로 지정하고 저장합니다.
6. 배포가 끝나면 표시되는 주소로 접속합니다.
